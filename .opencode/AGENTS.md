# OpenCode Development Rules

The documentation inside `/docs` is the single source of truth.

Never ignore the documentation.

Always read the documentation before implementing anything.

Do not invent features.

Do not remove existing features.

Use clean architecture.

Use reusable components.

Use SOLID principles.

Keep the project production ready.

Always run:

- lint
- build
- type check

before finishing every task.

After every task provide:

- Summary
- Files Changed
- Next Recommendation
