# Coding Rules

Always use:

TypeScript

Strict Mode

ESLint

Prettier

Server Components

Server Actions

TailwindCSS

Shadcn UI

Never use inline styles.

Never duplicate code.

Keep components small.

Use Feature Based Folder Structure.

Every feature must be modular.

Every API must include validation.

Every form must use Zod.

Every database access must go through Prisma.

Every commit should follow Conventional Commit.
